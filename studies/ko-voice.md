# Goal Lit 한국어 문체 가이드 (ko-voice, 2026-10-19 KST)
목적: Goal Lit의 문구(UI, 글 본문, 요약)를 한 사람의 목소리로 통일한다. 참조한 것은 평론가 신형철의 **태도와 리듬**이다. 공개된 서평·인터뷰·출판사 소개에서 자주 지적되는 특징을 요약했다. **그의 문장이나 구절은 옮기지 않는다.** 이 문서도 직접 인용을 하나도 싣지 않는다. 라벨: [공개자료 요약] [추정] [규칙].

## 1. 참조한 태도 (공개자료 요약)
1. **정확함이 윤리다.** 그는 비평의 덕목으로 '정확하게 말하기'를 거듭 앞세운다. 대상을 과장하지도, 깎아내리지도 않는 단어를 고르는 데 공을 들인다는 평이 많다 [공개자료 요약: 『정확한 사랑의 실험』 소개, 서평들].
2. **단정하되 겸손하다.** 판단은 분명하게 내리지만 "내가 읽기로는" 같은 자리에서 읽는 사람의 한계를 숨기지 않는다 [공개자료 요약: 인터뷰·서평].
3. **리듬.** 짧은 단언 뒤에 그 단언을 풀어 주는 긴 문장이 온다. 문단 끝은 대개 짧게 닫힌다 [추정: 저서 소개와 서평에서 공통으로 묘사되는 특징].
4. **개념어를 쉽게 푼다.** 어려운 말을 쓰면 바로 다음 문장에서 일상어로 다시 말한다 [공개자료 요약].
5. **대상에 대한 존중.** 작품을 깎아내리는 재치보다, 작품이 하려던 일을 먼저 말한다 [공개자료 요약].
6. **상투어와 번역투를 멀리한다.** '~를 통해', '다양한', '의미 있는' 같은 기성 표현 대신 구체어를 쓴다 [추정].

## 2. 우리 규칙 (톤 통일안) [규칙]
- **문장은 평서체 '-다'로 통일한다.** 글 본문, 요약, 소개, 원칙, 출처, 푸터의 문장 전부. 해요체·합니다체를 섞지 않는다.
  - 근거: 현재 posts 데이터는 해요체 657 / 평서체 570으로 반반 섞여 있다(혼용률 46.7%) [측정: ko_lint.py]. 평론의 목소리에는 평서체가 맞는다 [추정].
  - 이 규칙은 DISTILLED 17번(UI 해요체)을 **Goal Lit에 한해** 덮어쓴다. HANSET·Pitchboard에는 적용하지 않는다.
- **버튼·내비·라벨은 문장이 아니라 명사구나 동사 어간으로 쓴다**(예: '평론 읽기', '작품 찾기'). 2~4어절로 하고 마침표는 찍지 않는다. CLEAN_RULES R3(첫 화면 60어절 이하)를 지킨다.
- **빈 상태·안내 문구는 짧은 평서문 한 문장으로 쓴다.**
- **주어는 작품이나 매체이고, '저는/우리는'은 쓰지 않는다.** 필명 에디터의 체험담은 금지다(레포 가드).
- **판단은 출처에 묶는다.** '~라고 평했다', '~로 읽었다'처럼 누가 그렇게 말했는지를 문장 안에 남긴다.
- **한 문장에 한 생각을 담는다.** 한 문장이 60자를 넘으면 쪼갤지 검토한다. 문단은 짧은 문장으로 닫는다.
- **바꾸지 않는 것:** 사실, 숫자, 날짜, 작품명, 매체명, 인용된 평론 원문, 출처 제목, 가드 고정 문구(5장).

## 3. 바꾸는 방향 (예시는 우리 사이트 문구로만 든다)
| 피할 것 | 쓸 것 | 이유 |
|---|---|---|
| ~를 통해 다시 읽어야 한다고 해요 | ~를 거쳐 다시 읽어야 한다고 본다 / ~로 다시 읽자고 한다 | 번역투, 어미 혼용 |
| ~에 대한 평가 | ~를 두고 한 평가 / ~의 평가 | '에 대한'의 남용 |
| 다양한 해석이 시도됐다 | 해석이 여럿 나왔다 / 세 갈래로 읽혔다 | 상투어 대신 수와 구체어 |
| ~할 수 있어요 | ~한다 / ~일지 모른다 | 완곡의 남발을 줄인다. 불확실하면 그 이유를 쓴다 |
| 진정한 광장 | (원문 인용이면 유지) 아니면 구체 명사 | 상투어 |
| ~하고 있어요 | ~한다 | 진행형 직역 |

## 4. 기계 점검 (`tools/ko_lint.py`)
규칙: '~를 통해', '~에 있어(서)', '~에 대해/대한', '~에 의해', 이중피동, '~로 하여금/가지고 있다', '의 ~의' 연쇄, '~할 수 있습니다/있어요', '다양한/다채로운', 광고투(최고의·완벽한·지금 바로·만나보세요), '의미 있는/특별한/진정한', '것 같다/하는 것이다', '~하고 있다', '그것은/그녀는', 그리고 어미 혼용률(해요체·합니다체·평서체 중 다수 어미가 아닌 비율).
한계: 인용 원문, 출처 제목, 고유명사도 같이 잡힌다. 그래서 결과는 '후보 수'로 읽고, 사람이나 리뷰 세션이 의미를 판정한다 [규칙].
Goal Lit 기준선 [측정, 2026-10-19 main]:
- UI(build_site.py와 pages): 금지어 후보 2건, 해요체 113 대 평서체 1
- posts.json: 금지어 후보 150건(그중 '~에 대해/대한' 119건, 다수가 출처 제목), 혼용률 46.7%
- works.json: 후보 5건

## 5. 가드 고정 문구 (바꾸지 않음, 운영 봇과 조율 대상)
- `보관된 글이에요`: leak_check이 보관 글을 가려내는 표지다. 해요체지만 유지한다.
- `참고한 공개 자료`: 글 상세 출처 목록의 필수 문구다.
- framing 문구: '공개' + '종합/정리/요약' + 필명이 반드시 들어가야 한다(validate_post).
- tests/test_guards.py의 픽스처 문장(해요체)은 테스트 입력이므로 바꾸지 않는다.

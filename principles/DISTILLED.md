# DISTILLED — 반드시 지킬 원칙 (2026-10-19, 근거: studies/*.md)
Apple식 품질 = **여백, 큰 위계, 절제된 색, 짧은 모션, 접근성**. 아래 수치는 "기본값"이며 프로젝트 토큰으로 덮어쓸 수 있다. 라벨: [측정] [문서] [추정].

## A. 원칙 18개
1. **토큰만 쓴다.** 글자 크기·행간·색·간격·반경·모션 값은 토큰으로만 참조(raw hex/px 금지). Toss TDS도 하드코딩 금지 [문서]. 
2. **타입 위계는 화면당 3~4단계.** 제목/소제목/본문/캡션. 크기 단계는 크게 벌린다(Apple 80/56/40/28/24) [측정].
3. **본문 한 줄 폭 제한: 한글 40~55자(상한 60), 영문 45~75자.** 한글 평균 0.7em/자 → `max-width: 36em` 기본(≈50자) [측정 도출+문서].
4. **한글: `word-break: keep-all; overflow-wrap: break-word;`, 본문 line-height 1.6~1.7, 양끝정렬 금지** [문서+측정].
5. **큰 제목에만 좁은 자간.** 한글 제목 -0.01~-0.03em, 본문 0. 라틴 전용 히어로의 -6%는 한글 금지 [측정+추정].
6. **본문 17px(긴 글), UI 14~16px, 모바일 본문 ≥16px.** 11px 미만 금지 [문서 HIG min 11pt, SEED t1=11px].
7. **중립색 + 강조색 1개.** 강조색은 주요 액션과 링크에만. 순검정 대신 #1A1A1A~#333 계열 잉크 [측정].
8. **대비: 본문 4.5:1 필수, 긴 글은 7:1 지향, 큰 글 3:1, UI 경계 3:1.** 연한 강조색(예 #A78BFA)은 텍스트 금지, 채움/장식만 [문서].
9. **깊이는 그림자보다 표면색 단계 + 1px 라인.** 그림자는 1종 레이어 2겹 이하, 낮은 불투명도 [측정: Apple none, Vercel/Airbnb 링].
10. **곡률은 3단 + pill:** 컨트롤 8, 카드 12~16, 미디어/히어로 20~28, 버튼 pill(999). 같은 레이어는 같은 값 [측정].
11. **간격은 4px 기반 스케일** 4/8/12/16/24/32/48/64/96. 섹션 간격은 데스크톱 64~96, 모바일 40~56 [추정; HIG는 컨트롤 간 12/24pt 권장 문서].
12. **모션: 마이크로 120~160ms, 표준 200~320ms, 큰 전환 ≤400ms. transform/opacity 중심, ease-out 계열.** 기본 곡선 `cubic-bezier(0.2, 0, 0, 1)`(Airbnb)/`(0.4,0,0.2,1)`(Vercel) [측정]. `prefers-reduced-motion` 시 해제 [문서].
13. **인터랙션 타겟 44px(주요), 최소 24px(AA), 간격 ≥8px.** 포커스 링은 `:focus-visible`, 3:1, 고정 헤더에 가려지지 않게 [문서 HIG/WCAG 2.5.8, 2.4.11].
14. **모든 상태를 만든다:** hover/pressed/focus/disabled + 로딩, 빈, 에러. 에러는 해결 행동 포함 [문서 Apple/Toss].
15. **블러 헤더는 낮고 얇게:** 높이 44~64, 불투명도 0.8~0.96, blur 8~20px, 솔리드 폴백 [측정 Apple 44px/blur20, Goal Lit blur8].
16. **다크모드는 설계한다.** 시맨틱 토큰으로 라이트/다크 쌍 정의, 반전 금지, 고대비 확인. 브랜드가 라이트 전용이면 `color-scheme` 명시 [문서 HIG].
17. **UI 문구: 해요체, 능동, 긍정, 과한 경어 금지, CTA는 다음 행동 예측 가능** [문서 Toss].
18. **성능 예산: LCP ≤2.5s, INP ≤200ms, CLS ≤0.1 (75퍼센타일).** 폰트는 서브셋 woff2 + `font-display: swap` [문서 web.dev].

## C. Goal Lit 적용 시사점 5개 (측정 근거)
1. **글 상세 본문 폭 1044px → ≤ 36~40em(≈612~680px).** 현재 첫 줄 89자(WCAG AAA 40자, 사례 47~68자). 미디어/표만 넓게. 가장 효과 큰 단일 변경 [측정: goal-lit 글 상세 12개 단락].
2. **글자 크기 정리.** 홈 상위 폰트 크기에 11.52/12.8/13.6/14.08/14.4/17.28px 등 분수 px 다수 → 스케일(13/14/16/17/20/22/28/40)로 통합하고 토큰화 [측정: sizes histogram].
3. **강조색 접근성.** accent #A78BFA는 배경 대비 2.47:1이라 텍스트·얇은 선 금지, 채움/배지 배경 전용. 링크·강조 텍스트는 accent-d(6.76:1) [측정 색+계산].
4. **상태·모션 부재 보완.** site.css에 transition 0건, hover는 색 변경뿐. 카드/버튼에 120~200ms 색·transform 전환, pressed 상태, 모든 목록의 빈 상태 문구(해요체) 추가. `prefers-reduced-motion`은 이미 있음 [측정].
5. **디렉터리·에디토리얼 이중 구조.** 작품/장르/작가 목록은 리디식 밀도(표지 4px 반경, 14px 메타, pill 태그), 평론 글은 토스/브런치식 단일 칼럼. 출처 티어·확인일은 본문 하단 고정 블록과 상단 한 줄 요약 [측정+추정]. (잠금 규칙: noindex, CSP 인라인 style 금지, 별점·가짜 후기 금지는 변경 대상 아님)

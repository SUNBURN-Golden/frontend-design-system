### 1-3. 작품 상세
```
H1 작품명 · 작가 · 장르 칩(≤2) · 상태(연재/완결)       ← 작품 정보를 H1 아래 한 줄로 올림
평론 요약: 호평 n · 비판 n (이 작품을 다룬 글 카드 3개)  ← "평론"이 최상단, 정보 표는 아래
사람 평점 / 아직 확인하지 못한 것  ← 접기(기본 닫힘) 또는 한 줄
```
현재 순서(평론 → 에디터의 글 → 작품 정보 → 사람 평점 → 확인 못한 것)는 유지하되 171단어로 이미 짧다 [측정]. 작품 목록(40개 링크)은 **검색/장르 필터로 먼저 좁히기**를 권장 [추정].

## 2. Goal Lit 패턴 Top 10
1. **정체성은 H1 한 줄 + 보조 한 줄.** 이미 H1 29자(✔). 보조문은 80자 → ≤30자, 두 번째 문장은 푸터/소개로. [측정: Claude 로그인 20자/39자, Aeon 23자]
2. **첫 화면의 가장 큰 글자는 대표 평론 제목 하나.** 나머지는 작게. [측정: TNY 36px, Quanta 45px, 롱블랙 30px]
3. **1차 CTA는 1개 ("평론 더 보기")**, 나머지는 텍스트 링크. 현재 "편집 원칙" 버튼은 푸터 이동. [측정: 참고 사이트 CTA 0~2, Claude 입력+버튼 몇 개]
4. **내비 ≤4 + 더보기.** 현재 7. 평론/작품/장르 + 검색. 작가·신간·에디터·편집 원칙은 더보기·푸터·홈 중단 섹션으로. [측정: TNY 1, Atlantic 'flag'(문서: 로고+구독·검색·메뉴), Claude 0~4]
5. **카드는 4조각:** 작품명 · 제목(≤30자) · 호평/비판 요약 · 에디터/날짜. 현재 약 8조각. 요약문은 목록에서 제거(상세에서만). [측정: 참고 카드 3~7조각; 추정]
6. **한 화면 카드 5~6장, 홈 전체 평론 ≤10장 + "더 보기".** 현재 35장. [측정: Atlantic는 모듈형으로 첫 화면 항목을 의도적으로 줄였다고 문서화 — Poynter 2015]
7. **썸네일을 쓸 거면 3:2~16:9로 통일, 안 쓰면 "작품명 칩"을 시각 앵커로.** 이미지 자산이 없으면 텍스트 행(목록) 형태가 더 낫다. [측정: 참고 카드 1.5~1.9]
8. **글 칼럼 640px / 17~18px / 행간 1.7~1.9 / 한 줄 40~55자.** [측정: 롱블랙 580px·18px·1.9·49자]
9. **글 상단 "한눈에" 3줄 요약 + 메타 한 줄(에디터·날짜·읽는 시간·출처 수)**, 출처 목록은 하단 고정 블록. [추정: 상세 구조 근거 PR #1]
10. **흐름 끝에 항상 다음 한 걸음 1개:** 글 끝 → 같은 작품의 다른 글 / 작품 상세 → 평론 카드 / 홈 끝 → 평론 더 보기. [추정]
